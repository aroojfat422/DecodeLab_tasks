# decoodeLab 🚀

Welcome to my **CodeLab Repository**! This repository contains my programming, machine learning, and AI projects developed during my learning journey.

## 📂 Projects

### Project 1 – DecodeBot 🤖

A simple Python GUI chatbot built with **Tkinter**. It provides predefined responses to common user inputs.

**Technologies:** Python, Tkinter

### Project 2 – Basic Classification Model 📊

A supervised machine learning project that uses a **Decision Tree Classifier** to classify data and evaluate model performance.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib

### Project 3 – Movie Recommendation System 🎬

A Python Tkinter application that recommends movies based on the user's selected category.

**Technologies:** Python, Tkinter

### Project 4 – AI Image Recognition System 🖼️

A deep learning image classification system using a pre-trained **ResNet50** model to recognize objects and display the Top 5 predictions with confidence scores.

**Technologies:** Python, PyTorch, Torchvision, Pillow, Matplotlib
